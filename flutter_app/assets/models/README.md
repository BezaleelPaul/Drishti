# On-device model artifacts

## Primary grader: `drdetect_ordinal_512_fp32.tflite` (16.0 MB)

Ordinal-regression DR grader (DRDetect), the same weights the server runs
via onnxruntime (`efficientnet_b0_regression_512px.onnx`, QWK 0.8931 claimed
— **not yet independently verified in-repo**; see `results/drdetect_evidence.json`).
Converted to TFLite with `onnx2tf` and **parity-gated** against the ONNX
reference (`scripts/convert/validate_drdetect_tflite.py`):

| Check | Result | Gate |
|---|---|---|
| Grade agreement vs ONNX | **10/10** (100%) | >= 99.2% |
| Max absolute score diff | **3e-5** | <= 0.05 |

Input contract: float32 NHWC `[1,512,512,3]`, ImageNet-normalized
(mean/std, applied **outside** the graph in `DrDetectOrdinalTfliteRunner`).
Output: float32 `[1,1]` continuous severity score. Decoded with cut-points
`[0.5, 1.5, 2.5, 3.5]` (byte-parity with `src/classification/classifier.py`).
SHA-256: `8644E287098D347F2D91A6327ACD5ED90A263E6535A8308EEA4B5BF3B82CE3C0`.

Evidence: `results/drdetect_tflite_parity.json`, `results/drdetect_evidence.json`.

The runner also ports the Python preprocessing (dark-border crop → circle
crop → Ben Graham sigma=20 → area-resize 512). A measured working-size fast
path (blur at <=768 px, sigma scaled) keeps on-device cost acceptable;
drift vs the exact path is bounded at **0.059 score / 10/10 grade
agreement** (`results/drdetect_fastpreprocess_tolerance.json`). Dart golden
parity against the exact Python tensors: `flutter_app/test/fixtures/drdetect_preprocess_goldens.json`
(generated by `scripts/convert/generate_drdetect_dart_goldens.py`).
